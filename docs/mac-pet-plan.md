# Mac 桌面小精灵实施计划（2026-10-15）

目标：修复当前本机 Mac 同步助手没有小精灵、开关被隐藏的问题。沿用现有小蓝鱼，不改变任何同步项目、设备身份或引擎配置。

方案选择：复用 Tk 绘制及同一网关快照，按平台处理透明窗口；相比另建原生/网页宠物实现，减少行为分叉。新增独立生命周期控制器，支持 Windows/Darwin，其他平台与 headless 不启动。启动就绪后才确认开启，关闭/退出时只清理自己创建的宠物子进程。设置保存在既有 pet_enabled；右键关闭也通知主程序保存，不写其他配置。

## 0.3.17 人物透明回归（2026-11-09）

在 macOS 26.6.2 使用正式包的 Tcl/Tk 8.6.16 和帧图复现。透明 Aqua 窗口里的 Tk PhotoImage 人物区域 alpha 为 0，状态卡和进度环仍可见。切换为不透明窗口后人物可以绘制。

修补后由 AppKit 原生视图在同一窗口绘制人物帧，Tk 继续处理进度环、文字和鼠标事件。隔离运行 PetApp 验证了同步中、已送达、等待和待机出帧，人物、进度环和状态卡 alpha 为 1，背景角落 alpha 为 0。另用 PyInstaller 冻结探针验证了原生图层依赖和帧裁剪。

本次验证使用隔离进程，Mac 上的正式安装仍为 0.3.17。
