# 自身更新

现状：开发中。负责人：捞鱼工作室。最后更新：2026-09-30。

每日口径固定 UTC+8，分别记录尝试/成功日期；离线自动检查当日不反复尝试，手动可重试。只接受 x.y.z 正式新版，来源固定为 lyzbcy/laoyu-sync GitHub 发布与 raw 清单。

Windows 便携和安装版共用完整 ZIP 更新：后台下载到用户更新目录，核验原始 SHA-256 与安全解压。旧版退出后独立 helper 等待进程退出，把旧程序目录改名保留备份，再切换完整新版目录。用户数据在独立目录，更新不触碰 Syncthing 配置。新版启动回报健康，超时恢复旧目录，写更新结果并重启旧版。用户能看下载、校验、准备与失败状态；失败提供重试和发布页。

旧 0.2 源码版只有浏览器下载入口，首次需手动安装完整包。Mac 保留检查和下载页，未在 Mac 验收的一键替换不开放。
