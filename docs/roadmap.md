- [ ] 日志复制、失败文件处理提示、关于页、适度使用后求 Star 与 15 天免打扰。
- [ ] 每日/手动版本检查；可信下载、SHA-256、进度、升级重启和回滚。
- [ ] Windows EXE、内置引擎、许可证、安装/便携包与真实运行验证。

- [ ] 软件中心描述、目录与白名单登记、严格检查。
