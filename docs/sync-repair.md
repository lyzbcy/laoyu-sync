# 同步排查与修复

现状：Windows 本机开发版 0.3.16，支持从界面和本机脚本排查。
负责人：捞鱼工作室。
最后更新时间：2026-11-09。

- 「设置与关于 → 同步排查」提供仅排查、排查并自动修复。首页异常状态可直达。
- 运行中的客户端提供回环鉴权接口。开发目录执行 `python scripts/diagnose_sync.py` 仅排查，追加 `--repair` 进行同一套安全重试。结果包含项目与文件级原因，仅用于本机排查。
- 排查用 Syncthing 的状态、设备连接和文件错误。区分对端离线、没有可用数据块、文件占用、路径、磁盘空间、权限与文件名问题。文件错误优先读取 Syncthing 的 error 字段，兼容旧 message 数据。项目仍缺目录或删除操作时，待处理项也计入状态。
- 自动修复是用户发起的一次有界重试。文件占用仅在设备在线、项目未暂停、目录和标记存在、路径仍在项目内、文件存在且磁盘有空间时执行定向扫描。最多三项，间隔一分钟。引擎重试前核对没有当前实例，已有外部进程或进程不明时不接管。报告区分扫描已经执行和同步仍待确认。
- 设备离线、权限、磁盘、路径和命名问题给处理方法，由 Syncthing 在条件恢复后继续同步。项目暂停、设备身份和同步配置由用户管理。

验收：214 项隔离测试通过。定向扫描用真实隔离 Syncthing 和合成文件验证。本机真实项目仅执行只读排查。0.3.16 本机 D 盘安装、开始菜单冷启动、软件中心路径、原引擎进程及配置指纹已核对。
